Text typed in the wrong layout, fixed with one key

A Linux tool that converts text typed in the wrong keyboard layout (for example sghl instead of the Persian word for hello) into correct Persian or English with the F9 key, in any app.

How it works

Three moves, no switching apps

  1. 1

    Select the text

    In any app, select the text that was typed in the wrong layout.

  2. 2

    Press F9

    Each character becomes the one the same key gives in the other layout. GeekType works out the direction by itself.

  3. 3

    The right text replaces it

    The selection is replaced with the fixed text and your previous clipboard is put back.

Details

Small and precise

  • Any app

    Telegram, a browser, a terminal or system search. The app only needs to accept the usual select and paste.

  • Both directions

    Persian to English and English to Persian. With mixed text, the script that has more characters decides.

  • Standard layout

    The key table was checked against Ubuntu's official Persian layout file. Half-spaces, symbols and digits convert correctly, and an accidental Caps Lock is undone.

  • Clipboard untouched

    After every fix, the old clipboard content comes back. If nothing is selected, nothing is replaced.

Install

From the AppImage or from source

AppImage

Download the file, make it executable and run the install command. It asks for your sudo password to install packages and create the service.

chmod +x GeekType-x86_64.AppImage
./GeekType-x86_64.AppImage --install

Source

To run from the project folder. It only needs Python 3.8 or newer.

git clone https://github.com/mani-imani/GeekType.git
cd GeekType
python3 bin/geektype --install

If the AppImage does not start, install the libfuse2 package. To check everything after installing, run --doctor.

Requirements

What you need

  • Ubuntu with GNOME on Wayland. Only this combination has been tried.
  • wl-clipboard, ydotool and libnotify-bin. The install command sets them up.
  • The F9 shortcut is registered in GNOME settings and can be removed with --uninstall.
